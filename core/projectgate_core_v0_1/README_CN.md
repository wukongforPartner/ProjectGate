# ProjectGate Core v0.1

ProjectGate Core 是一个不绑定具体项目的 AI 协作治理层。

它把项目文档、操作流程、审查规则和事故经验整理成 AI 可以遵守的结构化工作流。

Core 不包含任何项目专属事实。项目专属知识应该放在 Project Pack。

## Core 职责

- 阶段门禁
- 事实优先
- 多角色分离
- Owner Decision 协议
- 预算档位
- Evidence Pack 与 Run Cache 策略
- SOP 生命周期
- Incident 生命周期
- KnownBugRule 生命周期
- AI 工具 Adapter 契约
- Project Pack 编译脚手架

## Core 不包含

Core 不应该包含具体项目路径、仓库名、领域术语、发版命令或产品专属流程。
