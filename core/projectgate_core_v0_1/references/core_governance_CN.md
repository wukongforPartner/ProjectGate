# Core Governance Standard v0.1

## 原则

1. 不猜。
2. 缺事实时停止推进或只读补事实。
3. 每个结论必须有来源。
4. 未知必须保持未知。
5. 提案者不能批准自己的提案。
6. 执行者不能作为最终验证者。
7. 破坏性动作必须有 owner 明确授权。
8. 成功流程进入 SOP candidate。
9. 可复现失败进入 KnownBugRule candidate。
10. 永久激活必须经过 owner 批准。

## 默认阶段

新的或模糊任务默认进入 `READONLY_AUDIT`。

## Owner 职责

Owner 负责价值判断、风险接受、写操作授权和候选知识激活。
