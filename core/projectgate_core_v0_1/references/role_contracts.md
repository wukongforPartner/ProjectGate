# Role Contracts v0.1

## Roles

- FactCollector: gathers facts only.
- Synthesizer: organizes facts into options.
- AdversaryReviewer: searches for missing facts, contradictions, and overreach.
- Gatekeeper: deterministic checker, not the same agent as the proposer.
- Executor: performs approved actions.
- Verifier: validates results independently from the executor.
- KnowledgeCurator: records SOP and incident candidates.
- Owner: makes value judgments and grants authorization.
