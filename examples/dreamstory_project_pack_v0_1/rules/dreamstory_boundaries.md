# DreamStory Project Boundaries

## Runtime fact

Runtime fact work must not proceed from one confirmed sample path to a patch. It requires an entry map that classifies all possible real code entry points before event names, fields, first-cut scope, or patches.

## Patch flow

Patch work requires current project facts, current git state, target file existence, real method structure, anchor map, and owner authorization.

## Unity scene protection

StartScene.unity is protected by default. Do not modify it unless owner explicitly authorizes that scope.

## Animation / Effect

Animation/effect work must respect the project's current animation ownership rules and must not introduce direct flush ownership outside the approved route.
