# ProjectGate Alpha Quick Start

1. Put project documents into a `ProjectDocsInbox` folder.
2. Run `install_projectgate_alpha.py` to initialize a ProjectGate workspace.
3. Compile a Project Pack from the docs.
4. Build a Codex pack from the Project Pack.
5. Install the Codex pack.
6. Use `/goal $projectgate -p L: ...` inside Codex.

Profile flags:

- `-p L`: low cost
- `-p M`: medium depth
- `-p H`: high depth
